# HiBaCaML experiment dependencies, beyond FabricPC itself.
#
# FabricPC (https://github.com/trueagi-io/FabricPC) must be installed
# separately in editable mode, PINNED TO v0.5.2 -- see README.md
# "Install FabricPC" for the exact commands and why the pin matters
# (FabricPC v0.6.0 replaced the node forward() contract with a
# predict()/energy() split that this repo's node code does not yet
# implement; installing an unpinned/latest FabricPC breaks graph
# construction entirely).
#
# The two packages below are imported by this repo but were previously
# undeclared anywhere, so a clean checkout + FabricPC install alone is
# not enough to run experiments/split_mnist.py end to end:
#
#   - matplotlib is required by hibacaml/reporting/plots.py
#     (experiments/split_mnist.py calls generate_plots() unconditionally
#     at the end of a run; without matplotlib this raises ImportError
#     only after a full training run has already completed).
#   - tensorflow is the primary path hibacaml/data/split_mnist.py uses
#     to fetch/cache MNIST via tensorflow.keras.datasets.mnist.load_data().
#     (A pure-numpy fallback exists that downloads mnist.npz directly,
#     but tensorflow/keras is tried first.)
